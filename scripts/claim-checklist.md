# Brian claim checklist (SSO)

1. Open https://go.terminal3.io/adk-community → Google sign-in on ADK page.
2. Optional campaign code (not required for 20k test credits).
3. **Copy API key immediately** (shown once) → store in local password manager as `T3N_API_KEY`.
4. Claim a **second** key for the agent → `AGENT_KEY` (own credits).
5. Never paste keys into GitHub, Earn form, or the public Google Doc.
6. Run `npm run auth` and `npm run agent:whoami`; paste only the `did:t3n:…` values into Earn + Doc.
